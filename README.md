
# IS2-TEAM

This code is for IS2-TEAM. Extracted features from integrated scan are inputs for IS2-TEAM, and it use same mapping thread as F2-LSLAM。


## System Requirements

### Software and Libraries:
Eigen\
PCL\
PDAL\
OpenCV\
Ceres\
Glog\
Gflag


### Hardware:

Backpack Systems


## Input and Output: 

The parameters in the setting file, which can process batch files:\
**-folder:** the input folder
**-setting:** the setting file

### Running Instructions: 

just run `IS2TEAM.exe Setting_file` directly
